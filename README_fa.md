## 🧠 معماری هسته‌ی CLXY

CLXY رابط کاربری Flutter را با یک هسته‌ی شبکه‌ی Goی تعبیه‌شده ترکیب می‌کند. هسته به‌صورت یک کتابخانه داخل اپ اجرا می‌شود. رابط کاربری از یک پل محلی و API لوپ‌بک برای مدیریت تنظیمات و خواندن وضعیت اتصال استفاده می‌کند، در حالی که هسته ترافیک شبکه را مدیریت می‌کند.

در حالت VPN، سرویس `VpnService` اندروید یک اینترفیس مجازی TUN می‌سازد. یک پشته‌ی TCP/IP در فضای کاربر بسته‌ها را پردازش می‌کند و اتصال‌های TCP را به پروکسی SOCKS5 هسته می‌فرستد. ریزالور داخلی DNS نام دامنه‌ها را به آدرس‌های IP موقت نگاشت می‌کند تا قوانین مسیریابی همچنان بتوانند دامنه‌ها را تشخیص دهند. این قوانین انتخاب می‌کنند که از پروکسی استفاده شود، اتصال مستقیم برقرار شود یا اتصال مسدود شود. انتخاب اپ‌ها هم مشخص می‌کند کدام برنامه‌ها از VPN استفاده کنند.

هسته برای اتصال به گیت‌وی از HTTP/2 CONNECT روی TLS و HTTP/3 CONNECT روی QUIC پشتیبانی می‌کند. حالت «فقط پروکسی» از همان هسته استفاده می‌کند بدون این‌که VPN سراسری روی دستگاه بسازد. مسیر VPN اندروید TCP و DNS را پوشش می‌دهد؛ بقیه‌ی ترافیک UDP تونل نمی‌شود.
